Производительность криптографических операций — важная характеристика любого устройства защиты информации.

Измерения проводились в следующей конфигурации. STM32F103C8T6 тактировался частотой 72 МГц (8-МГц кварц, PLL ×9). USB работал в Full Speed на 48 МГц. Время операций фиксировалось двумя способами: для коротких — счётчиком DWT с разрешением около 14 нс; для длинных — измерением интервала между запросом и ответом на стороне компьютера. Результаты приведены в таблице 5.1; значения средние по 100 повторам, разброс не более 5%.

Таблица 5.1 — Время выполнения операций и пропускная способность

| Операция | Параметр | Значение |
| CMD_PING | время отклика | 0,5 мс |
| belt-hash, 1 КБ | время / скорость | 1,3 мс / 770 КБ/с |
| belt-hash, 1 МБ | скорость | 1,1 МБ/с |
| belt-CBC, 1 КБ | время / скорость | 0,9 мс / 1,1 МБ/с |
| belt-CBC, 1 МБ | скорость | 1,1 МБ/с |
| bign-sign2 | время | 42 мс |
| bign-verify | время | 78 мс |
| CMD_GEN_KEYPAIR | время | 110 мс |
| Старт устройства | до готовности | 1,5 с |

Пропускная способность belt-CBC в 1,1 МБ/с приближается к теоретическому пределу программной реализации belt на 72-мегагерцовом Cortex-M3 (около 1,4 МБ/с). Реальные накладные расходы создаёт передача данных по USB пакетами по 64 байта. Время подписи bign-sign2 в 42 мс для интерактивной работы более чем приемлемо. Время проверки почти в два раза больше времени формирования, что характерно для алгоритмов на эллиптических кривых: проверка требует двух скалярных умножений, формирование — одного.

Полученные значения находятся в одном диапазоне с результатами bee2 на сопоставимых микроконтроллерах. Профессиональные USB-токены на специализированных кристаллах быстрее в 4–8 раз благодаря аппаратным ускорителям.
