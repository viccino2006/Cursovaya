# Cursovaya — программно-аппаратный комплекс криптографических преобразований по СТБ с USB

Курсовая работа: реализация криптографических преобразований по
стандартам **СТБ 34.101.31** (belt, belt-hash) и **СТБ 34.101.45**
(bign-sign / bign-verify) на микроконтроллере **STM32F103C8T6** с
обменом по USB CDC ACM.

## Состав репозитория

- `firmware/` — прошивка STM32 (модули bee2 как git-submodule + прикладной слой)
- `host/`     — программа ПК на Python 3 (CLI + Tkinter GUI)
- `docs/`     — текст курсовой работы и сборщик в `.docx`

Подробности — в PR.
